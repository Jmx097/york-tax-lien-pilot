# [P04] Build the first complete county-to-CSV path

## Assignment

Owner role: technical lead and source engineer. Target: days 3–5. Dependencies: one permitted usable source from P02 and the ingestion and state foundation from P03.

## Tasks

- [ ] Select the first county from observed usable permitted access, not a fixed preference.
- [ ] Discover complete approved windows. Retain restricted evidence and exact critical fields.
- [ ] Implement text extraction, a narrow fallback, and explicit holds for uncertain amount, address, or status.
- [ ] Produce a reviewed fixed-header CSV and test a real sample in the client's actual importer.

## Acceptance

- [ ] One real permitted source reaches a client-accepted reviewed sample, or the day-5 escalation cuts expansion.
- [ ] Every row has evidence and a reviewer. No row asserts a current IRS balance.
- [ ] Sample import proves a path. It does not prove four-county fulfillment, ongoing supply, or launch clearance.

## Done and exclusions

Sanitized demonstration evidence, a second reviewer, and documentation are required. Do not represent synthetic rows as source records, guess contact data, build universal OCR, or use unsafe file handling. A live transfer still requires the applicable launch gates.
